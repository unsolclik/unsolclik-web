# unsolclik · web de fotografia esportiva

Galeria i botiga de fotos d'esdeveniments esportius d'unsolclik.
Publicada amb GitHub Pages.

- `index.html` – la pàgina (configuració a l'inici del `<script>`: preus, contacte, esdeveniments)
- `fotos/` – vistes prèvies amb marca d'aigua (els originals no es pugen mai)
- `marca/` – logo

## Galeries privades per famílies (Pack Nadal)
- Pàgina: `tria.html#CODI` (no indexada a Google). Demo: `tria.html#demo`.
- Nova família: `python3 tools/nova-familia.py "Família Garcia" /carpeta/fotos` → posa marca d'aigua, afegeix-la a `families.js` i et dona l'enllaç.
- Preus a `families.js` (TRIA_CONFIG): 20 incloses, 2 € extra, +20 € totes.
